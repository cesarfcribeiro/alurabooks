# 📚 AluraBooks

Um projeto desenvolvido em **HTML e CSS** com o objetivo de recriar a página principal da **AluraBooks**, uma livraria digital com foco em livros de tecnologia, programação e design.

Este site foi criado como exercício prático de estruturação de páginas responsivas e aplicação de componentes visuais modernos.

## 🚀 Tecnologias utilizadas

- **HTML5** – estrutura e semântica da página  
- **CSS3** – estilização e layout responsivo  
- **Swiper.js** – biblioteca para o carrossel de livros  
- **Reset CSS** – para padronizar o estilo base entre navegadores  

---

## 📱 Funcionalidades

✅ Menu responsivo (hambúrguer)  
✅ Carrossel com os **últimos lançamentos** e **mais vendidos**  
✅ Seção de **tópicos visitados recentemente**  
✅ Campo de **busca** e **cadastro de e-mail**  
✅ Rodapé completo com links da **comunidade Alura**
